# House Price Prediction using Machine Learning

## Project Overview
This project uses Machine Learning to predict house sale prices using the Ames Housing dataset.

## Dataset
- Rows: 1,460
- Columns: 81
- Target Variable: SalePrice

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data loading and exploration
2. Missing value handling
3. Sale price visualization
4. Correlation analysis
5. Feature selection
6. Training and testing split
7. Linear Regression model training
8. Model evaluation
9. Actual vs predicted price comparison

## Model Results
- MAE: 24774.22
- RMSE: 39474.54
- R² Score: 0.7968 (79.68%)

## Conclusion
The Linear Regression model achieved an R² score of 0.7968 on the test dataset.
